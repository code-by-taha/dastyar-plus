# دستیار پلاس

یک داشبورد شخصی سبک و دوزبانه برای مدیریت کارها، مطالعه، ورزش، پروژه‌های کدنویسی و یادداشت‌ها. برنامه بدون حساب کاربری و سرور اجرا می‌شود و داده‌ها را در مرورگر خودت نگه می‌دارد.

[English](README.md)

راهنمای کامل [نصب و انتشار با GitHub Pages](DEPLOYMENT.fa.md) · [English guide](DEPLOYMENT.md)

## امکانات

- پروفایل شخصی با نام نمایشی، نقش و هدف فعلی
- رابط فارسی راست‌چین و انگلیسی چپ‌چین
- مدیریت کارها در برد و فهرست، با دسته‌بندی، اولویت، موعد، تکرار، جستجو و امکان ویرایش/تکمیل/حذف مستقیم
- جستجوی سراسری میان کارها، یادداشت‌ها، درس‌ها و پروژه‌ها
- درس‌ها، جلسات مطالعه، آزمون‌ها، فلش‌کارت، برنامهٔ هفتگی و تایمر تمرکز ۲۵/۵۰/۹۰ دقیقه‌ای
- ثبت تمرین، برنامه‌های ورزشی، وزن و عکس‌های پیشرفت
- فهرست پروژه‌ها و قطعه‌کدها، تایمر تمرکز و ویرایشگر اختیاری Monaco
- یادداشت، پوشه‌بندی، جستجو در متن و پیش‌نمایش Markdown
- تنظیمات ظاهر، فرمان‌های صفحه‌کلید و ورود/خروجی داده

## اجرا

نیازی به نصب وابستگی یا ساخت پروژه نیست. `index.html` را باز کن یا پوشه را با سرور محلی اجرا کن:

```bash
python3 -m http.server 8000
```

سپس به <http://localhost:8000> برو.

## انتشار با GitHub Pages

۱. مخزن را در GitHub قرار بده.
۲. از **Settings → Pages** وارد تنظیمات انتشار شو.
۳. گزینهٔ **Deploy from a branch**، شاخهٔ `main` و مسیر `/(root)` را انتخاب و ذخیره کن.

برای دستورهای دقیق، روش بارگذاری از وب‌سایت GitHub و عیب‌یابی، [راهنمای کامل انتشار](DEPLOYMENT.fa.md) را ببین.

## حریم خصوصی و ذخیره‌سازی

این برنامه بخش سرور ندارد. پروفایل و اطلاعات پنل در `localStorage` همین مرورگر ذخیره می‌شود و بین دستگاه‌ها یا مرورگرها همگام‌سازی نمی‌شود. پیش از پاک‌کردن داده‌های مرورگر، از مسیر **تنظیمات → داده → خروجی** نسخهٔ پشتیبان بگیر. فایل JSON را فقط از منبع قابل‌اعتماد وارد کن.

فضای ذخیره‌سازی مرورگر محدود است و عکس‌ها پیش از ذخیره کوچک می‌شوند. فونت‌ها، آیکون‌ها و ویرایشگر اختیاری Monaco در صورت دسترسی به اینترنت از CDN بارگذاری می‌شوند؛ در غیر این صورت برنامه با فونت جایگزین قابل استفاده است.

## مشارکت

برای گزارش مشکل یا پیشنهاد تغییر، Issue یا Pull Request ثبت کن. تغییرها باید هر دو زبان و جهت نوشتار را حفظ کنند. اطلاعات شخصی یا فایل خروجی پنل را در مخزن commit نکن.
